Steps
1. Create a private GitHub repository to hold your source code. The repository must have a README.md file, an appropriate License file, and a .gitignore file initialized for C language programs.



2. Create a Replit account (https://replit.com) if you do not already have one. A free account is sufficient for this exercise.



3. In the Replit user interface, select "Import Code or Design" from the left panel, then select "Import from GitHub". Connect your Replit and GitHub accounts using the control at the bottom of the screen, then enter the GitHub repo URL in the specified field, and start the import.



4. Select one of the Software Options listed in the last section, below.



5. Prompt the Replit AI to produce the application. Use the knowledge you have to design a prompt that produces a useable result. Make sure the application:

Meets the Software Option requirements.
Is written in the C language.
Runs on Linux and could execute on Matrix (i.e., can be built with the tools available on Matrix, such as the GCC compiler and Linux version installed there).


6. Monitor the Agentic AI as it produced the software.

Did it ask you for any clarification?
Did it test the software thoroughly?
Did it have to fix any errors or bugs?


7. Review the results:

Use the "Console" tab at the top of the Replit page to view the application. Try it out.
Use the "+" button in the tab bar at the top of the Replit page to open a Shell tab. Using the shell, review the files that are there, including data files and source code.


8. Prompt the AI to make any fixes required, as well as at least two enhancements or adjustments.



9. Test and review the results. Refine them as necessary. Make the output look good!



10. Prompt the AI to add at least one of the enhancements recommended in the Software Option list.



11. Test and review the results. Refine them as necessary.



12. Prompt the AI to update your GitHub repository with the local commits. When you do this, you will need to generate a Personal Access Token (PAT) within GitHub, and install that PAT as a "Secret" in Replit. Caution: use a "FIne-Graned Access Token" that permits Read and Write Content access only to the repository used for this lab. If you allow more access, your Agentic AI could potentially damage or delete your other repositories!

Software Options


Choose one of these options:



A. Transit Terminal Departures Board


This project simulates a simplified transit departure board. It requires time calculations and data structures.



The Base Assignment: Create a C program that reads a list of "Stops" and "Route Numbers and Names" from a text file and displays a real-time countdown (e.g., "501 Queen - Arriving in 4 mins").



The "Agentic" Challenge: Ask the agent to implement a live-refreshing terminal UI so the clock ticks down without the user pressing Enter.



Requirement: Style the user interface to match the colours of one of the GTA transit agencies (e.g., TTC, YRT, Go Transit).



Enhancements (pick at least one):



Service Alerts: Prompt the agent to randomly generate "Delay" or "Stalled" statuses based on a percentage chance.



Directional Logic: Add a toggle to switch between "Eastbound" and "Westbound" views.



B. Expense Splitter (The "Roommate" Tool)


The Base Assignment: Build a tool where users enter a total bill amount (such as Rent or Groceries), the number of people, and names. It should output exactly what each person owes. The too may have a CLI or full-screen terminal-based interface.



The "Agentic" Challenge: Tell the agent to implement "Weighted Splitting" (e.g., one person pays 60% of rent because they have the bigger room).



Enhancement:



Persistent Ledger: Have the agent write the results to a file (or files) so the debts accumulate between runs, and so that the details of the roommates (such as Names) don't have to be re-entered.



C. System Health Monitor


The Base Assignment: Fetch and display the current CPU utilization and available memory, updating the display once a second.



The "Agentic" Challenge: Add two horizontal bar graphs to show memory usage and current CPU utilization.



Enhancements (pick at least one):



Detail: Display the CPU utilization per core in addition to the total CPU utilization, and break down the memory usage by type (such as processes, buffer/cache, and kernel).



Process Killer: Add a feature where the user can type a PID to "Kill" a process directly from the app (using the kill() system call).



Alerts: Have the AI write code that sends a one-line email alert to an address (retrieved from a data file) if the CPU utilization or memory used exceed a threshold. (Tip: you may need to simulate exceeding the threshold to test this. Also, almost all mobile carriers have an email-to-SMS gateway that will forward short email messages to SMS; you could use this to receive text alerts).
